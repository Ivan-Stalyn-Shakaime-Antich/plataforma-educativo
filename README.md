# 📘 Plataforma Educativa

Plataforma web educativa orientada al fortalecimiento de competencias digitales para estudiantes universitarios.

---

# 🎯 Objetivo

Desarrollar competencias digitales mediante módulos educativos, recursos multimedia y actividades prácticas.

---

# 🧩 Funcionalidades

✅ Módulos educativos organizados  
✅ Recursos PDF descargables  
✅ Videos educativos integrados  
✅ Actividades prácticas  
✅ Diseño adaptable (Responsive)  
✅ Modo oscuro (preparado)  
✅ Navegación moderna
